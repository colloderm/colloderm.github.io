프로젝트 개요 Overview

혼자 또는 최대 3인 스쿼드로 좀비가 가득한 도시에 들어가, 다른 플레이어와 경쟁하며 장비를 모으고 제한 시간 안에 탈출하는 익스트랙션 게임입니다. 저는 플레이어 · 무기 · 게임 규칙 · 온라인 · 로비 UI를 맡아, 로비에서 장비를 고르고 파티를 꾸려 탐사에 들어갔다가 탈출하기까지의 흐름 전체를 C++로 구현했습니다.

게임 사이클

클래스 구조 Architecture

로비 기능은 레벨이 바뀌어도 유지되는 GameInstance 서브시스템으로, 탐사 규칙은 서버의 GameMode로, 플레이어 행동은 캐릭터와 GAS 어빌리티로 나눴습니다. 무기 수치는 데이터 에셋에 있어서 무기를 추가할 때 코드를 고치지 않아도 됩니다.

무기 · 사격 Weapon & Shooting

  • 권총 · 소총 · 샷건 · 저격총 4종과 근접 무기를 하나의 데이터 에셋 UOBWeaponData로 정의합니다. 원거리 · 근접 전용 항목은 EditCondition으로 필요한 무기에서만 보이게 했습니다.
  • 사격 모드는 단발 · 점사 · 연사, 반동은 수직 · 수평 · 회복 속도와 조준 시 배율로 조절하고 카메라 셰이크를 함께 줍니다.
  • 주무기 · 보조무기 슬롯을 두고, 바꿔 들어도 무기마다 탄창이 따로 유지됩니다. 같은 슬롯 키를 다시 누르면 무기를 내립니다.
  • 무기마다 기동성 배율이 있어 무거운 무기를 들면 걷기 · 달리기 속도가 줄어듭니다.
  • 총기는 같은 팀에게 피해를 주지 않고, 수류탄은 같은 팀도 다치게 했습니다.

서버 사격 판정 PerformServerWeaponTrace

탄은 화면 가운데 조준점으로 날아가야 하지만, 3인칭이라 총구와 카메라 위치가 다릅니다. 그래서 카메라에서 조준점을 먼저 구하고, 총구에서 그 지점으로 쏘도록 두 번 트레이스했습니다. 벽에 붙어서 총구가 벽을 뚫고 나간 경우와 카메라가 벽에 끼어 조준점이 뒤에 잡히는 경우도 따로 처리했습니다.

// OBGameplayAbility_RangedWeapon.cpp (일부)
// 1) 카메라에서 전방으로 트레이스해 실제 조준점을 구한다 (크로스헤어 = 화면 중앙)
FVector AimPoint = GetWorld()->LineTraceSingleByChannel(
    AimHit, CamLoc, CamEnd, OB_TraceChannel_Weapon, AimParams)
    ? AimHit.ImpactPoint : CamEnd;

// 카메라가 벽에 끼면 조준점이 총구 뒤에 잡혀 탄이 뒤로 나간다 → 카메라 전방으로
if (FVector::DotProduct(AimPoint - MuzzleLoc, CamRot.Vector()) <= 0.f)
{
    AimPoint = MuzzleLoc + CamRot.Vector() * WeaponData->Range;
}

// 벽에 밀착하면 총구가 벽 너머에 놓인다 → 시작점을 몸통으로 당긴다
const bool bMuzzleBlocked = GetWorld()->LineTraceSingleByChannel(
    MuzzleBlock, BodyOrigin, MuzzleLoc, OB_TraceChannel_Weapon, AimParams);
const FVector TraceStart = bMuzzleBlocked ? BodyOrigin : MuzzleLoc;

// 2) 샷건은 1회 발사에 여러 발이 각자 스프레드 콘 안으로 퍼진다
for (int32 PelletIndex = 0; PelletIndex < Pellets; ++PelletIndex)

GAS 어빌리티 Gameplay Ability System

플레이어 행동은 모두 GameplayAbility로 만들고, 무기를 장착할 때 그 무기의 UOBAbilitySet(데이터 에셋)이 필요한 어빌리티를 부여합니다. 입력은 Lyra 방식을 참고해 입력 액션을 GameplayTag에 연결하는 UOBInputConfig로 붙였습니다.

// OBGameplayAbility_RangedWeapon.cpp — 사격 모드 (일부)
// 첫 발 즉시
FireOneShot();
++ShotsFired;

// 단발: 1발 후 종료
if (CurrentFireMode == EOBWeaponFireMode::Single)
{
    EndAbility(Handle, ActorInfo, ActivationInfo, true, false);
    return;
}

// 점사 / 연사: RPM 간격으로 반복
World->GetTimerManager().SetTimer(FireTimerHandle, this,
    &UOBGameplayAbility_RangedWeapon::FireLoop,
    GetFireInterval(), true);

// 연사: 입력을 뗄 때까지 (커스텀 ASC 파이프라인)
if (CurrentFireMode == EOBWeaponFireMode::FullAuto)
{
    UAbilityTask_WaitInputRelease* WaitRelease =
        UAbilityTask_WaitInputRelease::WaitInputRelease(this, false);
    WaitRelease->OnRelease.AddDynamic(
        this, &UOBGameplayAbility_RangedWeapon::OnFireInputReleased);
    WaitRelease->ReadyForActivation();
}
설계 포인트
  • 사격 모드 셋을 어빌리티 하나에서 처리합니다. 단발은 바로 끝내고, 점사는 정해진 발수, 연사는 입력을 뗄 때 끝냅니다.
  • 연사 중 "버튼을 아직 누르고 있는지"는 직접 조종하는 기계에서만 확인합니다. 서버에 있는 원격 플레이어의 어빌리티에는 입력 상태가 없기 때문입니다.
  • 총구 화염 · 사격음은 탄 수와 관계없이 발사당 한 번만 GameplayCue로 보내 네트워크 부담을 줄였습니다.

게임 루프 · 탈출 Expedition Loop

  • 같은 파티는 같은 스폰 존에서 시작하고, 존 안에서는 네비메시 위의 랜덤 위치로 흩어져 스폰합니다.
  • 세션 타이머가 끝나면 아직 탈출하지 못한 인원은 실패(사망) 처리하고 결과 화면으로 보냅니다.
  • 팀원이 살아 있으면 쓰러져도 바로 죽지 않고 기절 상태가 됩니다. 30초 안에 부활하면 체력 35%로 일어나고, 아니면 사망합니다.
  • 사망한 플레이어는 살아 있는 팀원을 관전하고, 보던 팀원이 쓰러지면 다음 생존자로 자동 전환됩니다. 팀 전원이 끝나면 홈 화면으로 돌아갑니다.
생존→기절→부활 (체력 35%) 또는 기절→ 30초사망→관전 또는 생존→탈출

개인 탈출구 배정 SelectPersonalMarkers

탈출구가 늘 같은 자리면 동선이 외워져 긴장감이 사라집니다. 그래서 스폰 지점에서 충분히 먼 후보만 고르고, 같은 팀이 이전 판에 쓴 곳은 빼고, 두 번째 탈출구는 첫 번째와 방향이 충분히 벌어진 곳 중에서 랜덤으로 골랐습니다. 조건을 만족하는 후보가 없을 때는 조건을 하나씩 풀어 항상 배정되게 했습니다.

// OBExpeditionGameMode.cpp — 개인 탈출구 2곳 선택 (일부)
// 1. 스폰 위치에서 충분히 먼 탈출구만 후보 (없으면 전체로 완화)
if (M && FVector::Dist2D(SpawnOrigin, M->GetActorLocation()) >= MinSpawnDistance)
{
    Candidates.Add(M);
}

// 2. 먼 순으로 정렬 → 상위 FarPool 안에서 고른다 (매 판 변동)
//    같은 팀이 이전에 사용한 탈출구는 제외
TSet<TObjectPtr<AActor>>& Used = TeamUsedCenters.FindOrAdd(TeamId);

// 1번 탈출구: 팀 미사용 후보 중 랜덤
AActor* First = Avail[FMath::RandRange(0, Avail.Num() - 1)];

// 2번 탈출구: 1번과 방향각이 충분히 벌어진 후보 중 랜덤
const FVector Dir1 = (First->GetActorLocation() - SpawnOrigin).GetSafeNormal2D();
const float CosThreshold = FMath::Cos(FMath::DegreesToRadians(MinDirectionAngleDeg));
for (AActor* M : Avail)
{
    const FVector Dir2 = (M->GetActorLocation() - SpawnOrigin).GetSafeNormal2D();
    // dot <= cos(임계) ⟺ 두 방향의 각도 >= 임계
    if (FVector::DotProduct(Dir1, Dir2) <= CosThreshold)
        Divergent.Add(M);
}
