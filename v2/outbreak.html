OutBreak

3인칭 익스트랙션 생존 슈팅 (PvPvE), 완성

좀비가 가득한 도시에 최대 3인 스쿼드로 들어가 장비를 모으고, 다른 플레이어와 경쟁하며 제한 시간 안에 탈출하는 게임입니다. 저는 플레이어, 무기, 게임 규칙, 온라인을 맡아 로비에서 탈출까지의 흐름을 C++로 만들었습니다.

서버 사격 판정과 탈출구 배정을 직접 해 볼 수 있습니다원본 C++ 함수의 순서와 수치를 2D로 옮긴 데모입니다. 사격 판정과 탈출구 배정을 코드로 보여 줍니다데모와 같은 순서로 동작하는 실제 C++ 코드입니다. 에디터에서는 안 보이던 문제 두 가지원인을 찾아 고친 과정을 커밋의 실제 코드와 함께 남겼습니다.

전체 구조

로비 기능은 레벨이 바뀌어도 유지되는 GameInstance 서브시스템으로, 탐사 규칙은 서버의 GameMode로, 플레이어 행동은 캐릭터와 GAS 어빌리티로 나눴습니다.

무기와 사격

  • 권총, 소총, 샷건, 저격총 4종과 근접 무기를 데이터 에셋 UOBWeaponData 하나로 정의합니다. 원거리와 근접 전용 항목은 EditCondition으로 필요한 무기에서만 보이게 했습니다.
  • 사격 모드는 단발, 점사, 연사이고, 반동은 수직, 수평, 회복 속도와 조준 시 배율로 조절합니다.
  • 주무기와 보조무기를 바꿔 들어도 무기마다 탄창이 따로 유지되고, 무거운 무기를 들면 이동 속도가 줄어듭니다.
  • 총은 같은 팀에게 피해를 주지 않고, 수류탄은 같은 팀도 다치게 했습니다.

탐사 세션과 탈출 규칙

  • 같은 파티는 같은 스폰 존에서 시작하고, 존 안에서는 네비메시 위 랜덤 위치로 흩어집니다.
  • 세션 타이머가 끝나면 아직 탈출하지 못한 인원은 실패로 처리하고 결과 화면으로 보냅니다.
  • 팀원이 살아 있으면 쓰러져도 바로 죽지 않고 기절합니다. 30초 안에 부활하면 체력 35%로 일어납니다.
  • 사망한 플레이어는 살아 있는 팀원을 관전하고, 보던 팀원이 쓰러지면 다음 생존자로 넘어갑니다.
생존→기절→부활, 체력 35%
기절→ 30초 →사망→관전
생존→탈출

개인 탈출구 배정

OBExpeditionGameMode.cpp개인 탈출구 2곳 선택 (일부)
// 1. 스폰 위치에서 충분히 먼 탈출구만 후보 (없으면 전체로 완화)
if (M && FVector::Dist2D(SpawnOrigin, M->GetActorLocation()) >= MinSpawnDistance)
{
    Candidates.Add(M);
}

// 2. 먼 순으로 정렬 → 상위 FarPool 안에서 고른다 (매 판 변동)
//    같은 팀이 이전에 사용한 탈출구는 제외
TSet<TObjectPtr<AActor>>& Used = TeamUsedCenters.FindOrAdd(TeamId);

// 1번 탈출구: 팀 미사용 후보 중 랜덤
AActor* First = Avail[FMath::RandRange(0, Avail.Num() - 1)];

// 2번 탈출구: 1번과 방향각이 충분히 벌어진 후보 중 랜덤
const FVector Dir1 = (First->GetActorLocation() - SpawnOrigin).GetSafeNormal2D();
const float CosThreshold = FMath::Cos(FMath::DegreesToRadians(MinDirectionAngleDeg));
for (AActor* M : Avail)
{
    const FVector Dir2 = (M->GetActorLocation() - SpawnOrigin).GetSafeNormal2D();
    // dot <= cos(임계) ⟺ 두 방향의 각도 >= 임계
    if (FVector::DotProduct(Dir1, Dir2) <= CosThreshold)
        Divergent.Add(M);
}

에디터에서는 안 보이던 문제

두 문제 모두 에디터 PIE에서는 재현되지 않았고, 데디케이티드 서버와 패키징한 클라이언트에서 직접 확인하며 고쳤습니다.

매칭 후 데디케이티드 서버로 맵 이동이 안 됨

원인기본 온라인 서브시스템이 Steam이라, 게임 접속까지 Steam 네트워크로 처리되면서 전용 서버 IP로 이동하지 못했습니다.

해결게임 접속은 NULL 서브시스템과 IpNetDriver로 돌리고(bUseSteamNetworking=false), 친구와 파티와 세션은 Steam 서브시스템을 명시적으로 가져와 쓰도록 나눴습니다.

패키징 후 클라이언트에서 수류탄 소리와 이펙트가 안 나옴

원인폭발 연출을 Unreliable 멀티캐스트로 보낸 직후 서버가 수류탄 액터를 바로 Destroy해서, 클라이언트에서는 연출이 실행되기 전에 액터가 사라졌습니다.

해결멀티캐스트를 Reliable로 바꾸고, 폭발 후에는 숨김과 충돌 해제만 한 뒤 2초 뒤에 사라지게 했습니다.
